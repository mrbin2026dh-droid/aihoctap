User approved the no-chat PWA design and explicitly allowed replacing unavailable Stitch/Sonnet with the existing design system and independent agent review (24 October 2026). Do not send project files to Antigravity. Context7 CLI failed DNS; use primary library documentation. Keep PIN behavior unchanged.

## Shared wire contract
- Student entry `frontend/hoc/index.html`; teacher editor `frontend/hoc/teacher.html`. Scope `./`, no tutor imports or LLM requests.
- GET `/api/pwa/catalog`: `{schema_version:1,revision:string,courses:[{id,subject_id,subject_name,grade,title,lessons:[{id,title,version,question_count}]}]}`.
- GET `/api/pwa/lessons/{course_id}/{lesson_id}/{version}`: `{schema_version:1,course_id,lesson_id,version,title,content_markdown,questions:[{id,prompt,options:object,hint,kind:'choice'|'text'}]}`. Version is SHA256 of canonical public package, hash excludes `version`. Never expose correct answers or private rubrics. Immutable prior versions remain available.
- POST `/api/pwa/attempts`: student bearer auth; `{attempt_id:UUID,course_id,lesson_id,version,answers:object}`. Return `{attempt_id,course_id,lesson_id,version,status:'submitted',correct,total,score,needs_review,feedback:[{id,correct:boolean|null,hint}]}`. Identity derived server-side. Same id + same body returns same ACK; changed body conflict. Text needs teacher review. No LLM.
- GET `/api/pwa/me`: authenticated identity `{uid,student_name,grade,class_code}`. GET `/api/pwa/progress` returns `{attempts:[ACK]}` for own identity. Teacher GET `/api/pwa/teacher/results` returns results only after teacher auth.
- POST `/api/pwa/teacher/publish`: existing teacher auth; `{subject_id,subject_name,grade,lesson_id,title,content_markdown,questions:[{id,prompt,kind,options,correct_answer,hint}]}`; returns catalog. Course ID `{subject_id}-{grade}`. GET `/api/pwa/teacher/lesson/{course_id}/{lesson_id}` returns private latest editor document. No writes before valid contract/auth.
