# Mẫu handoff giữa các AI

Mỗi việc một tệp: `<từ>-<sang>-<việc>.md`, tối đa khoảng 30 dòng. AI nhận việc chỉ đọc `AGENTS.md`, phần trạng thái của `aisgk.md` và tệp này.

```
# <Tiêu đề việc>
Từ: <AI giao> → Sang: <AI nhận>   Ngày: <Asia/Bangkok>
## Mục tiêu (1–3 dòng)
## Tệp cần đọc (đường dẫn, càng ít càng tốt)
## Kết quả mong đợi (tệp nào, tiêu chí đạt)
## Ràng buộc / không được làm
## Xong thì chuyển cho: <AI>
```

Tệp xong việc giữ lại làm lịch sử, không xóa.
