# Bài thi từ một file Google Sheet — người dùng cài
Từ: Claude → Sang: Người dùng   Ngày: 27/10/2026

Làm theo `apps-script/sheet-exam/README.md` (5 phút):
1. Tạo Google Sheet mới → Tiện ích mở rộng → Apps Script → dán `apps-script/sheet-exam/Code.gs` → Lưu.
2. Tải lại Sheet → menu **Bài thi → Tạo mẫu** → Cho phép.
3. Triển khai → Tùy chọn triển khai mới → Ứng dụng web → Thực thi: Tôi; Truy cập: Bất kỳ ai → Triển khai.
4. **Gửi Claude địa chỉ `/exec`.** Claude dán vào `frontend/hoc/thi.js` và đưa lên trang (chưa có địa chỉ thì trang thi báo "Chưa cài địa chỉ bài thi").
5. Điền học sinh (HocSinh) và câu hỏi (DeThi), mở ứng dụng → **Vào bài thi** thử với 1 mã học sinh.
Lỗi gì gửi Claude ảnh màn hình + dòng Sheet liên quan.
